## 학원관리시스템

아카라(ACA2000) 같은 학원관리 프로그램의 핵심 기능을 담은 앱입니다. 소스는 `docs/academy.html` (화면) 과 `webapp/Academy.gs` (서버) 입니다.

| 메뉴 | 기능 |
|---|---|
| 홈 | 재원생 수, 오늘 수업·출석 현황, 이달 신규, 이달 수납·미납, 예정된 상담, 최근 상담 |
| 학생 | 명부(검색·상태·학년·반 필터, 외부일정 입력 여부), 등록/수정, 재원·대기·휴원·퇴원 처리, 학생별 상세(수강·**외부일정**·출결·수납·성적·상담), CSV |
| 외부일정 (학생 상세) | 학생마다 **일정 입력 링크**(`schedule.html?t=토큰`, 추측 불가한 40자리 토큰)를 복사해 학생·학부모에게 보내면 로그인 없이 다른 학원·고정 일정(일정명·요일 여러 개·시작/종료·메모)을 입력·수정. 같은 링크로 언제든 다시 고칠 수 있고 이름 외의 정보는 보이지 않음. [새 링크 발급]으로 기존 링크 폐기. 학생 상세에서는 외부 일정 + 우리 학원 정규/선행 수업을 색으로 구분한 주간 타임테이블로 보고, 강사가 [직접 입력·수정]도 가능. 최근 수정 시각 표시 |
| 시간 찾기 | 학생 여러 명을 고르고 수업시간·주당 횟수·이동 여유시간(외부 일정 앞뒤에 더함, 기본값은 관리자가 저장)·시간대·요일을 정하면, 외부 일정·정규·선행 수업을 모두 피해 학생들의 학원 수업·외부 일정(이동 여유 포함)을 **한 주간 시간표에 겹쳐서**(좌우 분할 없이 반투명 overlay, 겹칠수록 진하게) 보여주고, **모두 함께 가능한 구간을 초록으로 강조**("N명 모두 가능"). 칸에 마우스를 올리거나 누르면 누가 안 되는지 표시. 결과 위 학생 칩을 누르면 그 학생을 잠시 제외/포함하며 즉시 다시 계산(모두 포함/모두 제외). 초록 구간을 눌러 요일별 개설 시각을 고른 뒤 [이 시간으로 반 개설]을 누르면 반 등록 창에 반 종류·요일·시간·학생이 채워져 반 이름·담당만 넣으면 개설과 동시에 수강 등록 |
| 반·시간표(스케줄) | 반 등록(반 종류 정규/선행·담당 강사·요일별 시간·강의실·월 수강료·교재·진도·수업메모), 수강생 편성, 반 목록, 시간축 타임테이블. 관리자는 [시간 일괄 입력]으로 `반 이름 : 요일 시작-종료, …` 를 여러 줄 붙여넣어 한 번에 적용 |
| 수업 카드 | 홈 "오늘 수업"과 타임테이블 블록은 같은 카드: **반정보**(시간·반·담당·학생 명단) ↔ **진도**(교과·교재·진도·수업메모) 를 카드 안 버튼으로 전환. 진도의 [수정]은 강사도 가능. 학생 명단은 수강등록에서 실시간 계산. 교재는 카드에서 목록을 골라 바로 저장되고, 목록(`textbooks` 시트)은 진도 수정 창에서 추가(강사 가능)·삭제(관리자) |
| 출결 | 반별 일일 출석체크(출석·지각·결석·조퇴·보강), 비고, 월간 출결표, CSV |
| 수납 (원장만) | **등록일 기준 매월 청구**: 청구일 = 그 달의 등록일 날짜(등록일 3/15 → 매월 15일), 금액 = 청구일에 수강 중인 반의 수강료 합계(반이 바뀌면 다음 청구일부터 반영). 청구일 전이면 "예정", 지났는데 덜 냈으면 "미납". 납부 등록(현금·카드·계좌이체), 미납자 문자(청구일 지난 학생만), CSV. 등록일은 학생 수정 창 또는 학생관리부 시트의 `등록일` 열(P열, `YYYY-MM-DD`; 가져오기/내보내기 모두 제목명으로 찾음)에서 바꾼다. 시트에 등록일이 없는 학생은 빈 값으로 들어오고(오늘 날짜를 지어내지 않음), 내보내기는 앱에 등록일이 있을 때만 P열을 써서 시트에 사람이 적은 값을 지우지 않는다 |
| 성적 | 시험 등록, 반별 점수 입력, 평균·최고·최저, 학생별 성적 추이, 성적표 문자 |
| 상담 | 재원생 상담·신규 문의 기록, 다음 상담 예정일, 신규 문의를 학생으로 바로 등록 |
| 문자 | 반·학년·전체·오늘 결석자·미납자 대상, 템플릿({이름} {반} {월} 등 자동 치환), 휴대폰 문자앱 연동 또는 알리고 자동 발송, 발송 기록 |

- 권한: **관리자(원장)** 전체. **강사**는 학생·출결·성적·상담·문자와 학생관리부 내보내기를 쓰고, 수납·삭제·아이디 관리·학생관리부 가져오기는 할 수 없습니다 (서버에서 검사).
- 아이디 관리(관리자): 아이디 만들기·수정·비활성·삭제. 자기 자신과 마지막 관리자는 삭제할 수 없고, 삭제한 아이디의 근무·상담 기록은 남으며 담당하던 반의 담임은 비워집니다.
- **데이터 흐름**: 학생관리부 구글시트(원장 드라이브) → [학생관리부 가져오기](원장만) → Apps Script `importRoster` 가 시트를 읽어 앱 데이터 시트(`students`·`classes`·`enrollments`)에 갱신 → 화면이 `bootstrap` 으로 다시 읽어 메모리 상태로 표시. 학생관리부 시트는 이 버튼을 누를 때만 읽는다(홈 [새로고침]은 앱 데이터 시트를 다시 읽을 뿐 학생관리부는 안 읽음). 브라우저에는 로그인 토큰만 저장되고 학생 데이터 캐시는 없다.
  - 읽는 탭: 이름에 "학생관리부"가 든 탭 → 없으면 1행에 성명·학생ID 제목이 있는 첫 탭 → 없으면 첫 탭. 열은 1행 제목명으로 찾고(위치 고정 없음), 학생은 `학생ID`(앱의 `extId`) → 없으면 이름+학년으로 맞춘다(이름만으로는 안 맞춤).
  - 내보내기는 시트 값을 앱 값으로 쓰되, 학교·연락처·비고·등록일은 앱이 비어 있으면 시트 값을 그대로 둔다. 최근 가져오기/내보내기 결과(시각·탭·인원·실패 사유)는 `settings` 시트에 남아 학생 화면 위에 "동기화 완료/실패"로 보인다.
- **버전**: 서버는 `webapp/Code.gs` 의 `SERVER_VERSION`, 화면은 `docs/academy.html` 의 `EXPECTED_SERVER` 한 곳씩. 화면 오른쪽 위 `v17` 칩이 화면 버전이고, 서버 버전이 다르면 옆에 "서버 vNN"으로 함께 보인다.
- 데이터 시트: `students` `classes` `enrollments` `attendance` `payments` `exams` `scores` `consults` `messages` `textbooks` `extSchedules`(학생 외부 일정) `scheduleLinks`(학생별 입력 링크 토큰) `settings`(이동 여유시간 기본값) (처음 쓸 때 자동 생성).
- 로그인 없이 부를 수 있는 요청은 `login` 과 일정 입력 링크용 `pubSchedule` `pubScheduleSave` 뿐이며, 이 둘은 링크 토큰이 맞을 때만 그 학생의 이름과 일정만 다룬다 (Code.gs `PUBLIC_ACTIONS`).
- 미납 계산: 그 달에 수강 중인 등록(시작일~종료일)의 수강료 합계 − 그 달을 청구월로 하는 "수강료" 납부액.
- 학생관리부 가져오기: 학생 탭의 [학생관리부 가져오기](관리자만)를 누르면 서버가 드라이브의 "학생관리부" 시트(`Academy.gs` 의 `ROSTER_SHEET_ID`)를 읽어
  정규반·선행반을 반으로, 각 행을 학생으로 만들고 수강을 맞춥니다. 학생ID(없으면 이름+학년)로 찾아 갱신하므로 여러 번 눌러도 중복되지 않고,
  앱에서 고친 연락처·메모는 지우지 않습니다. 담임(예: 성경자T)은 같은 이름의 강사 아이디가 있을 때 연결되며, 나중에 아이디를 만들고 다시 가져오면 채워집니다.
  가져온 반의 수강료는 0원이므로 반·시간표에서 채워 넣어야 수납 청구가 계산됩니다.
- 학생관리부로 내보내기: 학생 탭의 [학생관리부로 내보내기]는 반대로 앱의 학생·반·수강을 그 시트의 첫 탭에 써 넣습니다.
  강사도 누를 수 있습니다. 서버가 원장 계정 권한으로 쓰기 때문에 강사에게 시트를 공유할 필요가 없고, 시트는 원장만 열면 됩니다.
  앱이 원본이 되어 시트의 학생 목록이 앱과 같아지고(앱에서 지운 학생은 빠짐), 진도·확인처럼 앱에 없는 열은 학생ID 가 같은 행의 값을 그대로 남깁니다.
  학생ID 가 없는 학생에게는 S0001 식으로 번호를 새로 매깁니다. 반이 여러 개면 " / " 로 이어 쓰고, 가져오기도 그 표기를 읽습니다.
  자동으로 실시간 동기화되는 것은 아니며, 마지막에 누른 쪽(가져오기/내보내기)이 기준이 됩니다.
- 문자: 기본은 앱이 내용을 만들어 휴대폰 문자앱으로 넘기고 기록만 남깁니다. `Academy.gs` 의 `SMS` 에 알리고(aligo.in) API 키·아이디·발신번호를 넣으면 서버에서 바로 보냅니다.

### 학원관리 설치 (근무일지가 이미 설치되어 있다는 전제)

1. 데이터 시트의 [확장 프로그램] → [Apps Script] 를 엽니다. 기존 `Code.gs` 내용을 저장소의 `webapp/Code.gs` 로 바꿉니다 (학원관리 액션을 함께 처리하도록 바뀌었습니다).
2. [파일 추가] → 스크립트, 이름 `Academy` → `webapp/Academy.gs` 내용을 붙여넣고 저장.
3. [배포] → [배포 관리] → 연필 → 버전 **새 버전** → 배포. 주소는 그대로이므로 `config.js` 는 바꾸지 않아도 됩니다.
4. https://mmmath0110-del.github.io/mmmath01/academy.html 을 열어 관리자 아이디로 들어갑니다. 반을 먼저 만들고 학생을 등록하세요.

### 서버 자동 업데이트 설정 (한 번만)

화면(`docs/`)은 main 에 합치면 GitHub Pages 가 자동으로 반영하지만, 서버(Apps Script)는 구글 안에 있어 원래는 코드를 붙여넣고 새 버전으로 배포해야 합니다.
아래를 한 번 해 두면, 그 뒤로는 서버가 바뀔 때 학원관리 화면 위에 뜨는 **[서버 업데이트]** 버튼(관리자만)으로 끝납니다.
서버가 GitHub `main` 의 `webapp/` 파일을 직접 받아 자기 프로젝트에 넣고 새 버전을 만들어 웹 앱 배포를 바꿉니다.

1. https://script.google.com/home/usersettings 에서 **Google Apps Script API** 를 **사용** 으로 켭니다.
2. Apps Script 편집기 왼쪽 **프로젝트 설정(톱니)** → **"appsscript.json" 매니페스트 파일을 편집기에 표시** 를 체크합니다.
3. 파일 목록에 생긴 `appsscript.json` 을 열어 저장소의 `webapp/appsscript.json` 내용으로 바꿉니다 (`oauthScopes` 가 들어 있습니다).
4. `Code.gs`, `Academy.gs` 도 이번 한 번은 저장소 내용으로 바꾸고 저장합니다.
5. 함수 목록에서 `setup` 을 골라 ▶ 실행하고, 새로 요구하는 권한(Apps Script 프로젝트 관리 등)을 허용합니다.
6. [배포] → [배포 관리] → 연필 → **새 버전** → 배포. (이번이 마지막 수동 배포입니다)

이후 서버 코드가 바뀌면(`Code.gs` 의 `SERVER_VERSION` 이 올라가면) 화면에 배너가 뜨고, [서버 업데이트] 를 누르면 30초쯤 뒤 새 버전이 켜집니다.
버튼이 권한 오류(HTTP 403)로 막히면 편집기에서 함수 `updateFromGitHub` 를 ▶ 실행하세요. 같은 일을 하면서 필요한 권한 허용 창을 띄워 줍니다.
`checkUpdateAccess` 를 실행하면 Apps Script API 접근 여부와 응답이 로그에 찍혀 원인을 알 수 있습니다.
그래도 안 되면 예전처럼 직접 붙여넣어 배포하면 됩니다. 코드를 고치는 사람은 `SERVER_VERSION` 을 잊지 말고 올려야 합니다.

## 선생님 출결관리 대시보드

선생님들이 출근·퇴근 버튼으로 근무를 기록하고, 그날 한 업무를 적는 공유 대시보드입니다.
관리자는 전원의 기록과 아이디 관리, 선생님은 본인 기록만 봅니다 (서버에서 걸러서 내려줌).
주간 / 월간 / 시트(날짜·선생님·출근·퇴근·시간·업무내용·비고) 세 가지로 봅니다.
두 가지 배포본이 있고 화면은 같습니다.

|---|---|---|
| **웹 앱** (권장) | `docs/` → GitHub Pages, 데이터는 구글시트 | 링크를 아는 사람 누구나. 아이디·비밀번호로 열람 |

### 웹 앱 설치 (한 번만)

1. **데이터 시트**: 이미 만들어져 있습니다 → [더블엠 학원관리 데이터](https://docs.google.com/spreadsheets/d/1TNHAyqMIj43wRvaFtAp8eu4KOIPItcWzYy3ZFtxusMs/edit). 학원관리·근무일지 데이터가 모두 이 파일의 탭에 저장됩니다.
   `Code.gs` 의 `SHEET_ID` 에 이 시트 ID 가 들어 있습니다. 다른 시트를 쓰려면 그 값을 바꾸세요.
2. 그 시트에서 메뉴 [확장 프로그램] → [Apps Script] → `webapp/Code.gs` 내용을 붙여넣고 저장.
   함수 목록에서 `setup` 을 골라 ▶ 실행 (권한 허용).
   시트 `members` `logs` `sessions` 와 관리자 아이디 `mmmath01` / 비밀번호 `0000` 이 만들어집니다.
3. [배포] → [새 배포] → 유형 **웹 앱**, 실행 계정 **나**, 액세스 **모든 사용자** → 배포. 나온 URL(`https://script.google.com/macros/s/.../exec`) 복사
4. `docs/config.js` 의 `MM_API_URL` 에 그 URL 을 넣고 커밋 (현재 배포된 URL 이 들어 있습니다)
5. GitHub 저장소 [Settings] → [Pages] → Source: **Deploy from a branch**, Branch **main**, 폴더 **/docs** → 저장.
   (현재 이렇게 설정되어 있습니다. main 에 커밋하면 1~2분 뒤 사이트에 반영됩니다.)
   공유 주소: **https://mmmath0110-del.github.io/mmmath01/** — 이 주소를 선생님들께 전달하세요.
6. 관리자로 들어가 **아이디 관리**에서 비밀번호를 바꾸고 선생님 아이디를 만듭니다.

`Code.gs` 를 고친 뒤에는 [배포] → [배포 관리] → 연필 → **새 버전** 으로 다시 배포해야 반영됩니다.

- 비밀번호는 시트에 솔트 + SHA-256 해시로만 저장됩니다. 로그인 세션은 2주 유지됩니다.
- 권한 검사는 서버(Apps Script)에서 합니다. 선생님은 본인 근무만, 관리자는 전체 + 아이디 관리.
- 데이터는 구글시트에 그대로 보이므로 시트에서 바로 확인·백업할 수 있습니다. 시트를 직접 고치는 것보다 앱에서 고치는 편이 안전합니다.
