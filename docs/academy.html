반 등록

반 변경

수강 종료

기록은 지난 수강 이력에 남습니다. 학생관리부 시트의 반 칸도 함께 갱신됩니다.

중복 수강 정리

중복 수강 검사

보강 등록

대상 학생을 고르면 그 시간에 다른 수업·학원 일정이 있는지 자동으로 확인해 알려줍니다. 저장한 뒤 [안내 문자]로 학부모나 학생에게 보내면 되고, 학생은 자기 일정 링크에서도 볼 수 있습니다.

외부 일정 입력

학생이 링크로 입력하는 것과 같은 곳에 저장됩니다. 한 일정에 요일을 여러 개 고를 수 있고, 요일마다 시간이 다르면 일정을 따로 추가하세요.

수업정보 수정

이 반의 교과·교재·현재 진도·수업 메모를 고칩니다. 강사도 고칠 수 있습니다.

반 시간 일괄 입력

한 줄에 반 하나씩 반 이름 : 요일 시작-종료, 요일 시작-종료 형식으로 적습니다. 반 이름은 일부만 맞아도 되고, 여러 반이 맞으면 모두 바뀝니다. 요일은 월목 17:00-19:00처럼 붙여 쓰면 같은 시간으로 들어갑니다. 예: 중3 - 최상위월토 : 월 20:00-22:00, 토 10:00-12:00

납부 등록

청구월 기준으로 미납이 계산됩니다. 수강료는 학생 등록일의 날짜에 매월 청구되므로(등록일 3/15 → 매월 15일), 9월 수강료를 8월 말에 냈다면 청구월을 9월로 두세요.
